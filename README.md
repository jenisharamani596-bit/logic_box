# LogicBox

**Author:** Jenisha Ramani  
**Course/Project:** Python Practical Assignment

A simple Python menu-driven program to practice loops, conditions, patterns, and number analysis.

## Features

- Generate star patterns
- Check Even and Odd numbers
- Calculate the sum of numbers
- Simple menu-driven program

## Concepts Used

- For Loop
- While Loop
- If-Else
- Range Function
- User Input
- Arithmetic Operators

## Menu Options

1. Generate a Pattern
2. Analyze a Range of Numbers
3. Exit
